为什么用它

任意 Agent × 任意模型

一个本地网关同时支持 OpenAI Chat、OpenAI Responses、Anthropic Messages 和 Gemini 四种协议，双向转换，任何 Agent 都能用任何厂商的模型。

订阅共享

在任一 Agent 里登录过 Claude、ChatGPT、Copilot，这个登录就成了所有 Agent 都能用的供应商，令牌按原方式自动刷新。

多账号智能路由

一个模型背后可以挂多个密钥和账号：智能、按顺序、轮流、按权重等九种策略；限流自动退避、额度用完自动切换，Agent 看不到错误。

本地脱敏

打开后，请求离开电脑前把 API key、邮箱等敏感值换成占位符，回复时再换回来；原值只在内存里，从不落盘。默认关闭。

不动你的配置

只改 Agent 配置里需要的那几个键，注释、顺序、缩进原样保留，原子写入；断开连接时精确还原。

小巧原生

约 15 MB，基于系统 WebView，没有 Electron；菜单栏应用、TUI、命令行和 Docker 都有。

快速开始

方式一 · 从源码构建（现在就能用）

git clone https://github.com/cq0206/freemagpie.git
cd freemagpie
make build        # 桌面版（macOS / Windows / Linux）
make cli          # 纯终端版（交叉编译友好）

需要 Go 1.26+；Linux 桌面版还需要 GTK 3 与 WebKitGTK 4.1。

方式二 · 下载预编译版本

到 GitHub Releases 获取各平台安装包（首次发布准备中，可先用源码构建）。
