为什么用它

任意 Agent × 任意模型

一个本地网关同时支持 OpenAI Chat、OpenAI Responses、Anthropic Messages 和 Gemini 四种协议，双向转换，任何 Agent 都能用任何厂商的模型。

订阅共享

在任一 Agent 里登录过 Claude、ChatGPT、Copilot，这个登录就成了所有 Agent 都能用的供应商，令牌按原方式自动刷新。

多账号智能路由

一个模型背后可以挂多个密钥和账号：智能、按顺序、轮流、按权重等九种策略；限流自动退避、额度用完自动切换，Agent 看不到错误。

本地脱敏

打开后，请求离开电脑前把 API key、邮箱等敏感值换成占位符，回复时再换回来；原值只在内存里，从不落盘。默认关闭。

不动你的配置

只改 Agent 配置里需要的那几个键，注释、顺序、缩进原样保留，原子写入；断开连接时精确还原。

小巧原生

基于系统 WebView，没有 Electron；提供桌面应用、TUI 和命令行。安装包内置所需界面资源，下载大小以各平台文件为准。

安装与首次使用

  1. macOS：解压 ZIP，将 magpie.app 拖入“应用程序”并打开。首次若被拦截，确认下载来自本仓库后，在“系统设置 → 隐私与安全性 → 仍要打开”中允许。
  2. Windows：下载对应 EXE 并运行，需要 Microsoft Edge WebView2 Runtime。本版未签署发布者证书，系统可能提示未知发布者。
  3. Linux：先安装运行库，再给文件执行权限。Ubuntu 示例：
sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0
chmod +x magpie-linux-amd64
./magpie-linux-amd64

ARM64 电脑请将示例文件名中的 amd64 换为 arm64。终端版无需 GTK；macOS / Linux 下载终端版后也需要 chmod +x。

打开后，连接你的第一个 Agent

  1. 在“供应商”中添加你自己的 API key，或按供应商提供的方式登录。
  2. 确认至少有一个可用模型，再到 Agent 列表选择已安装的 Agent 和模型，完成连接。
  3. 重新打开 Agent，发送一条测试消息。网关默认运行在 127.0.0.1:3425。

已有 magpie 用户请先退出旧实例，FreeMagpie 复用原配置目录。终端版可运行 magpie --help，或用 magpie web 启动浏览器界面。具体模型是否可用取决于你的供应商账号与额度。

从源码构建

git clone --branch freemagpie https://github.com/cq0206/freemagpie.git
cd freemagpie
make build        # 桌面版
make cli          # 纯终端版

需要 Go 1.26.8+；Linux 桌面构建还需要 GTK 3 与 WebKitGTK 4.1 开发包。
